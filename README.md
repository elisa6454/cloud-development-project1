# Flask Web App – Cloud Dev Assignment
This project is a Flask-based web application developed as part of the Cloud Development 2024 module.

## 💻 Features
- Multi-page website using **Flask** and **Jinja2** templating
- Form input (email + message) saved to `comments.txt`
- Basic HTML/CSS for UI structure
- Routing with Python backend
- Static content and assets served with Flask
- Developed and version-controlled using **Git**

## 🛠 Tech Stack
- Python
- Flask
- HTML/CSS
- Git

## ✅ What I Learned
- How to build and structure a Flask web app
- Handling forms and file I/O with Python
- Serving static content with Flask
- Version control with Git & GitHub
